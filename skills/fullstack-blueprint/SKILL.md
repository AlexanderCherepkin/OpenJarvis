# Протокол Full-Stack разработки (Contract-First & Verified Build)

При получении задачи на разработку программного продукта выполняй строго 4 фазы:

## Фаза 1: Выбор стека и фиксация контрактов
1. Если стек не задан явно, выбери оптимальную связку под нагрузку задачи (Rust Axum / Go Fiber / Python FastAPI / Bun Hono для API; Next.js / SvelteKit / SolidStart / Tauri для клиента; PostgreSQL / SQLite / Redis / Qdrant для хранения).
2. Зафиксируй структуру каталогов, контракты данных/API и переменные окружения до написания бизнес-логики.

## Фаза 2: Реализация слоёв и запись файлов на диск
1. Обязательно создавай и обновляй реальные файлы в рабочей директории проекта через инструменты работы с файлами/терминалом, а не ограничивайся текстовым описанием.
2. Реализуй валидацию входных данных, обработку ошибок и `/health` эндпоинты.
3. Подготовь зависимости и команды запуска/проверки.

## Фаза 3: Автоматическая верификация
1. Запусти статическую проверку / линтеры и тесты.
2. Проверь работу эндпоинтов и ключевых сценариев реальными командами.

## Фаза 4: Самокоррекция
Если любая команда вернула ненулевой код выхода — разбери причину ошибки, внеси правки и повтори проверку до прохождения тестов.
