# Продуктовый пайплайн (PRD -> Plan / Issues)

1. **Write-a-PRD:** Опиши цель, пользовательские сценарии, функциональные требования, нефункциональные ограничения и критерии приёмки в `C:/OpenJarvis/docs/plans/<slug>-prd.md`.
2. **Маршрутизация:** Для задач в рамках одной сессии сформируй план (`prd-to-plan`); для многоэтапных проектов нарежь атомарные задачи с критериями готовности (`prd-to-issues`).
