# Типизированная CLI-память проекта

1. Перед крупным изменением проверь накопленные решения и баги по проекту (`claudemem search "<запрос>" --project C:/OpenJarvis`).
2. После решения нетривиальной проблемы зафиксируй запись типа `decision` или `gotcha` кратко (< 1500 токенов на обмен), без дублирования сырых логов.
