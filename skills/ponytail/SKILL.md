# Минимальный дифф и защита от оверинжиниринга

1. Изменяй только код, необходимый для решения текущей задачи; не добавляй лишних обёрток и зависимостей.
2. Проверяй все места вызова изменяемых функций и сохраняй обратную совместимость контрактов.
3. При создании MVP с нуля не подключай тяжёлую инфраструктуру без явного запроса.
