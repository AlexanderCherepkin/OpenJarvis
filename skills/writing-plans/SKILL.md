# Декомпозиция плана реализации

1. Разбей задачу на последовательные атомарные шаги (1 шаг = 1 логическое изменение в 1–2 файлах).
2. Для каждого шага укажи точный путь файла (`C:/OpenJarvis/...`), ожидаемый интерфейс и команду проверки (`pytest`, `ruff`, `curl`).
3. Выполняй шаги строго по одному с верификацией каждого шага.
